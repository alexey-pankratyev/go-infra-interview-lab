# Module 01 - Go Fundamentals Exercises

This folder contains practical exercises for Module 01.

## Lessons

1. `lesson-01-pointers-receivers-mutation/` - pointers, receivers, and mutation semantics

## Working Pattern

Each lesson should include:

- `theory.md` for the short practical foundation
- `find-bug/` for predict-output or bug-hunting practice
- `mini-script/` for a small runnable implementation task

Run Go practice files from their exercise directory with:

```bash
go run main.go
```

Do not read corrected solutions before attempting the task.
