# Study Repository Layout

Use stable, predictable paths so future sessions can continue without searching through scattered files.

## Top-Level Files

- `README.md`: curriculum overview, module order, and how to use the repository.
- `progress/progress.md`: current module, completed lessons, open tasks, and checklist state.

## Notes

Use `notes/` for concise topic summaries and interview cheat sheets.

Suggested files:

- `notes/go-fundamentals.md`
- `notes/slices-maps.md`
- `notes/memory-gc.md`
- `notes/concurrency-runtime.md`
- `notes/networking-systems.md`
- `notes/testing-profiling.md`

## Exercises

Use `exercises/` for prompts, user answers, reviews, and corrected examples.

Suggested naming:

- `exercises/module-01-fundamentals.md`
- `exercises/module-02-slices-maps.md`

## Code

Use `code/` for draft snippets and corrected Go examples.

Suggested naming:

- `code/module-02-slice-aliasing.go`
- `code/module-04-worker-pool.go`

## Save Rules

- Update existing module files when material belongs to the same module.
- Add a new file only when it improves navigation.
- Keep saved answers concise unless the exact wording is useful for review.
