# go-infra-interview-lab

Repository for structured Golang interview prep focused on Senior DevOps / Platform Engineer roles.

## Goal

Refresh Go quickly and deeply with emphasis on:

- systems programming
- concurrency and Go runtime internals
- memory management and allocations
- networking and HTTP clients/servers
- production debugging, testing, and profiling

This repo stores:

- study plan
- progress by module
- exercises and answers
- short notes and cheat sheets
- draft Go code and corrected examples

## Study structure

1. Quick Go fundamentals refresh
2. Arrays, slices, and maps under the hood
3. Memory management and allocations
4. Concurrency and Go runtime internals
5. Systems programming and networking
6. Testing, race detection, benchmarking, and profiling
7. Final interview drill

## Repository layout

- `progress/progress.md` — module checklist and current status
- `notes/` — short summaries and cheat sheets
- `exercises/` — tasks, answers, and reviews
- `code/` — draft Go snippets and corrected examples

## Working mode

The study flow is interactive:

- one module at a time
- one practical task at a time
- answer first, review after
- focus on interview-relevant production reasoning, not textbook trivia
