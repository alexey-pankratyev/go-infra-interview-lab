# Starter Prompts

Use these prompts to start or resume the Go infrastructure interview mentor flow.

## Start the Program

```text
@go-infra-interview-lab, начнем подготовку к Senior Platform / DevOps Go interview. Покажи только high-level структуру модулей и спроси подтверждение перед первым уроком.
```

## Resume Current Module

```text
@go-infra-interview-lab, продолжим с текущего модуля. Напомни 2-3 ключевые идеи и дай ровно одну практическую задачу без решения.
```

## Generate Next Exercise

```text
@go-infra-interview-lab, дай следующую задачу по текущему модулю. Соблюдай ротацию: predict/find bug, micro-function, production scenario.
```

## Review My Answer

```text
@go-infra-interview-lab, проверь мой ответ как code review для senior Go/platform interview: что правильно, что рискованно, какие runtime нюансы я пропустил, и только потом покажи корректное решение.
```

## Save Progress to GitHub

```text
@go-infra-interview-lab, сохрани текущий прогресс в GitHub. Используй alexey-pankratyev/go-infra-interview-lab на main, обновляй существующие файлы, не сохраняй полный transcript.
```

## Sync Module State

```text
@go-infra-interview-lab, синхронизируй состояние модуля: текущий модуль, закрытые упражнения, weak spots и следующий рекомендуемый шаг.
```

## Create Topic Notes

```text
@go-infra-interview-lab, создай короткие interview-focused заметки по текущей теме. Сохрани только high-signal нюансы: runtime behavior, production risks, edge cases, testing/debugging.
```

## Practice Runtime Explanation

```text
@go-infra-interview-lab, задай вопрос, где нужно объяснить Go runtime behavior под интервью: memory, scheduler, channels, maps, HTTP transport или profiling. Одну задачу, без решения до моего ответа.
```

## Debug Production Scenario

```text
@go-infra-interview-lab, дай production debugging scenario для Go platform engineer: симптомы, код или описание системы, и попроси меня найти root cause и fix plan.
```

## Safety Reminder for Repository Writes

```text
@go-infra-interview-lab, перед записью в GitHub проверь, что путь внутри go-infra-interview-lab, нет выхода через .. или absolute path, нет sensitive data, и ничего не удаляй без моего явного запроса.
```

## Deletion Request Template

```text
@go-infra-interview-lab, удали из репозитория go-infra-interview-lab файл <repo-relative-path>. Перед удалением подтверди, что путь внутри репозитория, и кратко перечисли, что будет удалено.
```

## Sensitive Data Check

```text
@go-infra-interview-lab, проверь материалы перед сохранением: если найдешь токены, ключи, kubeconfig, cloud credentials, passwords, cookies, database URLs или лишние персональные данные, подсвети категорию и место, но не сохраняй секреты как есть.
```
