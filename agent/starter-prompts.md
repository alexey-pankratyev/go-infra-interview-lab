# Starter Prompts

Use these prompts to start or resume the Go infrastructure interview mentor flow.

## Start the Program

```text
@go-infra-interview-lab, let's start preparing for a Senior Platform / DevOps Go interview. Show only the high-level module structure and ask for confirmation before the first lesson.
```

## Resume Current Module

```text
@go-infra-interview-lab, let's continue from the current module. Remind me of 2-3 key ideas and give exactly one practical task without the solution.
```

## Generate Next Exercise

```text
@go-infra-interview-lab, give me the next task for the current module. Follow the rotation: predict/find bug, micro-function, production scenario.
```

## Review My Answer

```text
@go-infra-interview-lab, review my answer like a code review for a senior Go/platform interview: what is correct, what is risky, which runtime nuances I missed, and only then show the corrected solution.
```

## Save Progress to GitHub

```text
@go-infra-interview-lab, save the current progress to GitHub. Use alexey-pankratyev/go-infra-interview-lab on main, update existing files, and do not save the full transcript.
```

## Sync Module State

```text
@go-infra-interview-lab, sync the module state: current module, completed exercises, weak spots, and the next recommended step.
```

## Create Topic Notes

```text
@go-infra-interview-lab, create short interview-focused notes for the current topic. Save only high-signal nuances: runtime behavior, production risks, edge cases, testing/debugging.
```

## Practice Runtime Explanation

```text
@go-infra-interview-lab, ask a question where I need to explain Go runtime behavior in an interview context: memory, scheduler, channels, maps, HTTP transport, or profiling. One task only, without the solution before my answer.
```

## Debug Production Scenario

```text
@go-infra-interview-lab, give me a production debugging scenario for a Go platform engineer: symptoms, code or system description, and ask me to find the root cause and fix plan.
```

## Safety Reminder for Repository Writes

```text
@go-infra-interview-lab, before writing to GitHub, verify that the path is inside go-infra-interview-lab, there is no .. traversal or absolute path, there is no sensitive data, and do not delete anything without my explicit request.
```

## Deletion Request Template

```text
@go-infra-interview-lab, delete the file <repo-relative-path> from the go-infra-interview-lab repository. Before deleting, confirm that the path is inside the repository and briefly list what will be removed.
```

## Sensitive Data Check

```text
@go-infra-interview-lab, check the materials before saving: if you find tokens, keys, kubeconfig, cloud credentials, passwords, cookies, database URLs, or unnecessary personal data, highlight the category and location, but do not save secrets as-is.
```
